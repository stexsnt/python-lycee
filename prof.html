Espace professeur

  1. Chaque élève ouvre sa page Profil, indique son prénom et sa classe, puis clique sur « Code pour mon professeur ».
  2. Il vous envoie ce code par l'ENT, par message ou dans un document partagé.
  3. Collez ici tous les codes reçus, toutes classes mélangées : ils se rangent seuls, et le texte autour des codes est ignoré.

Sauvegarde

Les classes sont conservées dans ce navigateur. Pour les retrouver sur un autre poste, enregistrez un fichier de sauvegarde ici, puis restaurez-le là-bas : les deux jeux de données sont fusionnés.

Tout est calculé dans ce navigateur. Les codes y restent enregistrés jusqu'à ce que vous les effaciez ; rien n'est envoyé sur Internet.
